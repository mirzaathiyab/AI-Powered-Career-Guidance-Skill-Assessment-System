#  AI-Powered Career Guidance & Skill Assessment System

##  Overview
This project is a Flask-based web application that helps students and professionals:
- Assess their **technical skills** at framework level (e.g., Pandas, NumPy, TensorFlow).
- Get **weighted skill scores** and mapped levels (Beginner → Expert).
- Receive a **personalized career roadmap**.
- Validate their learning through **quizzes with instant feedback**.
- Align with **UN Sustainable Development Goals**: 
  - SDG 4 (Quality Education)
  - SDG 8 (Decent Work and Economic Growth)
  - SDG 9 (Industry, Innovation and Infrastructure)

---

## ⚙️ Features
- ✅ Skill selection via modern UI cards  
- ✅ Framework rating (sliders 0–5)  
- ✅ Weighted scoring system (Beginner → Expert)  
- ✅ Personalized career roadmap (month-by-month)  
- ✅ Quiz system with solution review (user vs correct)  
- ✅ Chart.js visualization of skill profile  
- ✅ Aligned with SDGs for impact  

---

## Tech Stack
- **Backend:** Flask (Python)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** JSON / SQLite
- **Visualization:** Chart.js
- **Deployment Ready:** Docker / Cloud compatible
